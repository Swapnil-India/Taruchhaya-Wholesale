# Taruchhaya Wholesale - Inventory Management System

A premium, modern, and efficient inventory management system designed for wholesale business. Built with a focus on speed, mobile compatibility, and ease of use.

![Developed by Swapnil Sarkar](https://img.shields.io/badge/Developed%20by-Swapnil%20Sarkar-blue?style=for-the-badge)
![Tech Stack](https://img.shields.io/badge/Stack-HTML%20|%20CSS%20|%20JS%20|%20Vite-orange?style=for-the-badge)

## 🚀 Key Features

- **Smart Dashboard**: Real-time overview of total stock, low-stock items, and total products.
- **Advanced Inventory Management**: 
    - Add, edit, and delete products.
    - Track categories, SKU/Barcodes, and pricing.
- **Barcode/QR Scanner**: Integrated camera-based scanner for quick stock identification and adjustment.
- **Business Day Reports**: 
    - Group movements (Inward/Outward) by date.
    - **Finalize Day** feature to archive history and reset the business day.
    - Secure **Owner Verification** for sensitive reports and deletion.
- **Printable Reports**: Generate professional, printable summaries of daily stock movements.
- **Premium UI**: Dark-mode compatible, responsive design with smooth animations and Lucide icons.
- **Offline First**: All data is stored securely in the browser's LocalStorage.

## 🛠️ Technology Stack

- **Frontend**: Vanilla HTML5, CSS3 (Modern Flex/Grid), and JavaScript (ES6+ Modules).
- **Icons**: [Lucide Icons](https://lucide.dev/).
- **Barcode Scanning**: [html5-qrcode](https://github.com/mebjas/html5-qrcode).
- **Build Tool**: [Vite](https://vitejs.dev/).

## 📦 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Version 14 or higher)
- npm (comes with Node.js)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/[YOUR-USERNAME]/taruchhaya-wholesale.git
   cd taruchhaya-wholesale
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
